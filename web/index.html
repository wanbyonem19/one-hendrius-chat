ONE HENDRIUS CHAT

Aplikasi belum terhubung ke Firebase.

Supaya chat ini bisa dipakai siapa saja, pemilik aplikasi harus mengisi config Firebase dulu di file index.html (bagian FIREBASE_CONFIG), lalu build ulang APK / deploy ulang link-nya.

  1. Buat proyek gratis di console.firebase.google.com
  2. Aktifkan Authentication > Email/Password
  3. Buat Firestore Database (mode produksi) + Storage
  4. Salin config web-nya ke FIREBASE_CONFIG
  5. Pasang Rules dari file firestore.rules dan storage.rules

Panduan lengkap ada di file PANDUAN_FIREBASE.txt di folder proyek.
